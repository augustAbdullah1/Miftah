- 📊 **تتبع الأسعار** والتوصيات الذكية

## 🚀 **طرق تشغيل التطبيق | How to Run the App:**

### 1️⃣ **على الجوال | Mobile (Android/iOS):**
```bash
# تحميل Expo Go من متجر التطبيقات
# Download Expo Go from App Store

# تشغيل التطبيق
npx expo start

# مسح QR Code بـ Expo Go
# Scan QR Code with Expo Go
```

### 2️⃣ **على المتصفح | Web Browser:**
```bash
# تشغيل نسخة الويب
npx expo start --web

# أو استخدام الملفات المبنية
npx serve dist -p 8080
```

### 3️⃣ **بناء APK | Build APK:**
```bash
# إنشاء حساب Expo
npx expo register

# تسجيل الدخول
npx expo login

# بناء APK
eas build --platform android --profile preview
```

## 📋 **خطوات الاستخدام | Usage Steps:**

### 🔐 **التسجيل والدخول | Registration & Login:**
1. افتح التطبيق واختر "إنشاء حساب جديد"
2. أدخل بياناتك (الاسم، البريد الإلكتروني، كلمة المرور)
3. تحقق من بريدك الإلكتروني لتفعيل الحساب
4. سجل الدخول بالبيانات المُدخلة

### 🏠 **الصفحة الرئيسية | Home Screen:**
- 🔍 **البحث**: ابحث عن المنتجات بالكلمات المفتاحية
- 📂 **الفئات**: تصفح المنتجات حسب الفئة
- ⭐ **المميزة**: المنتجات المميزة والمقترحة
- 🔥 **الجديد**: أحدث المنتجات المضافة

### 💬 **نظام الرسائل | Messaging System:**
- 📱 **دردشة فورية** مع البائعين
- 🎤 **رسائل صوتية** مع تحويل نص
- 🌍 **ترجمة تلقائية** للرسائل
- 😊 **ردود ذكية** مقترحة
- 💰 **إرسال عروض** مباشرة في الدردشة

### 🎯 **نظام المزايدة | Auction System:**
- 🏆 **مزايدة مباشرة** على المنتجات
- 🤖 **مزايدة تلقائية** بحد أقصى
- 💳 **اشتري الآن** بسعر ثابت
- 📊 **تتبع المزايدات** والإشعارات

## 🚨 **استكشاف الأخطاء | Troubleshooting:**

### ❌ **مشاكل شائعة | Common Issues:**

**1. التطبيق لا يعمل على الجوال:**
- تأكد من تثبيت Expo Go
- تأكد من الاتصال بنفس الشبكة
- أعد تشغيل Metro bundler

**2. مشاكل Firebase:**
- تأكد من إعدادات Firebase في `src/config/firebase.ts`
- تحقق من مفاتيح API

**3. مشاكل الترجمة:**
- تأكد من ملفات الترجمة في `src/i18n/`
- أعد تشغيل التطبيق بعد تغيير اللغة
